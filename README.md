## 🧩 Problems Solved

### 01. Check if a Year is a Leap Year

Determines whether a given year is a leap year based on standard Gregorian calendar rules.

**Function:**

```javascript
isLeapYear(year)
```

**Example:**

```text
Input: 2024
Output: true
```

---

### 02. Generate Fibonacci Sequence Up to N Terms

Generates the first `n` numbers of the Fibonacci sequence starting from `0` and `1`.

**Function:**

```javascript
generateFibonacci(n)
```

**Example:**

```text
Input: 7
Output: [0, 1, 1, 2, 3, 5, 8]
```

---

### 03. Calculate the Greatest Common Divisor (GCD)

Calculates the Greatest Common Divisor of two non-negative integers using **Euclid's Algorithm**.

**Function:**

```javascript
findGCD(a, b)
```

**Example:**

```text
Input: 48, 18
Output: 6
```

---

### 04. Calculate the Least Common Multiple (LCM)

Calculates the Least Common Multiple of two positive integers using the relationship between **LCM and GCD**.

**Function:**

```javascript
findLCM(a, b)
```

**Example:**

```text
Input: 12, 18
Output: 36
```

---

### 05. Check if a Number is Prime

Determines whether a given positive integer is a prime number.

**Function:**

```javascript
isPrime(num)
```

**Example:**

```text
Input: 29
Output: true
```

---

### 06. Merge Two Sorted Arrays

Merges two already-sorted arrays into a single sorted array **without sorting the combined array again**.

**Function:**

```javascript
mergeSortedArrays(arr1, arr2)
```

**Example:**

```text
Input: [1, 3, 5], [2, 4, 6]
Output: [1, 2, 3, 4, 5, 6]
```

---

### 07. Find the Median of an Unsorted Array

Finds the median value of an unsorted array.

For an even-length array, the average of the two middle values is returned.

**Function:**

```javascript
findMedian(nums)
```

**Example:**

```text
Input: [7, 1, 3, 4, 9]
Output: 4
```

---

### 08. Find the Second Largest Number

Finds the **second distinct largest** number from an unsorted array.

**Function:**

```javascript
findSecondLargest(nums)
```

**Example:**

```text
Input: [10, 20, 4, 45, 99, 99]
Output: 45
```

---

### 09. Find the Most Frequent Element (Mode)

Identifies the element that appears most frequently in an array.

**Function:**

```javascript
findMode(arr)
```

**Example:**

```text
Input: [1, 3, 3, 2, 1, 3, 4]
Output: 3
```

---

### 10. Natural Sorting of Strings with Embedded Numbers

Sorts strings containing numbers in **natural numeric order**, so that `file2.txt` correctly comes before `file10.txt`.

**Function:**

```javascript
naturalSort(arr)
```

**Example:**

```text
Input:
["file10.txt", "file2.txt", "file1.txt"]

Output:
["file1.txt", "file2.txt", "file10.txt"]
```
